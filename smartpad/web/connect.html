Use your phone with this computer

Browsers can't move the mouse by themselves, so this computer needs the small SmartPad helper running.

Set up (once)

  1. Download SmartPad Helper and unzip it anywhere (right-click → Extract All).
  2. Double-click SmartPad Helper.exe. Nothing to install, no Python needed. If Windows SmartScreen warns, click More info → Run anyway.
    macOS/Linux: use the with-python folder and run sh start_helper.sh (needs Python 3.9+).
  3. A page with your own QR code opens. Scan it with your phone: that phone controls this computer only.

Already ran the helper? Its window shows the link to your QR code page.
